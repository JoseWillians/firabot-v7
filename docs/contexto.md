# Contexto

## Resumo

Bot de WhatsApp em TypeScript para atendimento academico, conforme README do projeto.

## Stack confirmada

- TypeScript e Node.js.
- Baileys para conexao com WhatsApp.
- MySQL para estado, logs e documentos.
- Docker Compose para banco local.

## Pendente de confirmacao

- Ambiente final de producao.
- Politica de retencao de logs.
- Fluxos administrativos futuros.
